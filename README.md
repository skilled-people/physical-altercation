# 몸개그 대전

흐물흐물한 동물 인형으로 상대를 때리고, 붙잡고, 물에 던져 넣는 3D 웹 파티 게임입니다.
설치 없이 브라우저에서 바로 실행되고, 키보드와 휴대폰 터치 모두로 할 수 있습니다.

## 실행 방법

- 내 컴퓨터에서: `index.html`을 브라우저로 열면 됩니다.
- GitHub Pages: 저장소 설정의 Pages에서 배포 브랜치를 고르면 `https://아이디.github.io/저장소이름/` 주소로 열립니다.

3D 엔진(Three.js r128)과 글꼴은 인터넷에서 불러오므로 인터넷 연결이 필요합니다.

## 게임 모드

| 모드 | 설명 |
|---|---|
| 난투 | 상대를 물에 빠뜨리면 1점, 라운드 끝까지 살아남으면 1점. 9라운드 합계로 우승자를 가립니다. |
| 축구 | 빨강팀과 파랑팀이 공을 펀치해 상대 골대에 넣습니다. 3골을 먼저 넣으면 라운드 승리. |
| 공 가져오기 | 공 5개 중 4개를 우리 팀 원 안에 모으면 바로 이깁니다. |

난투에서는 라운드마다 경기장 모양과 장애물이 무작위로 바뀌고, 얼음 지옥, 회전 지옥, 스프링 지옥, 거대 진자, 사라지는 육각판 같은 이벤트가 섞여 나옵니다.

## 조작

| 동작 | 키보드 | 휴대폰 |
|---|---|---|
| 이동 | WASD 또는 방향키 (카메라 기준) | 화면 왼쪽 끌기 |
| 시점 돌리기 | 마우스 (게임 화면을 누르면 고정, Esc로 해제) | 화면 오른쪽 빈 곳 끌기 |
| 점프 | Space | 점프 버튼 |
| 펀치 | Q 또는 J | 펀치 버튼 |
| 잡기 / 던지기 | E 또는 K | 잡기 버튼 |
| 돌진 | Shift 또는 L, 방향키 두 번 빠르게 | 돌진 버튼 |
| 캐릭터 능력 | F 또는 I | 능력 버튼 |

- 펀치에 맞으면 1.5초, 던져지면 0.75초 동안 흐물흐물해져 움직일 수 없습니다.
- 펀치를 연달아 맞으면 기절하고, 기절한 상대는 잡아서 던질 수 있습니다.
- 상대에게 들리면 리듬게임이 뜹니다. 박자에 맞춰 방향키를 2번 맞히면 반격해서 빠져나옵니다.
- 상대를 들고 있으면 평소보다 7배 크게 비틀거립니다.

## 캐릭터와 능력

| 캐릭터 | 능력 | 효과 |
|---|---|---|
| 분홍곰 | 땅 쿵 | 뛰어올랐다 내려찍어 주변 상대를 날립니다 |
| 파랑냥 | 냥냥 펀치 | 펀치 3번을 빠르게 날립니다 |
| 노랑꽥 | 꽥 소리 | 앞쪽 상대를 밀어내고 어지럽게 만듭니다 |
| 초록깡총 | 슈퍼 점프 | 공중에서도 높이 뛸 수 있습니다 |
| 보라펭 | 배 미끄럼 | 길게 미끄러지며 부딪힌 상대를 날립니다 |
| 주황여우 | 순간이동 | 바라보는 방향으로 5m 이동합니다 |
| 복숭아돼지 | 돌덩이 몸 | 3초 동안 커지고 무거워져 거의 밀리지 않습니다 |
| 갈색멍멍 | 질주 | 3초 동안 아주 빨리 달립니다 |
| 흑백판다 | 회전 휘두르기 | 빙글 돌며 주변 상대를 날립니다 |
| 연두개굴 | 혀 낚아채기 | 멀리 있는 상대를 끌어옵니다 |

## 온라인 대전에 대해

온라인 대전은 claude.ai 아티팩트가 제공하는 실시간 방(room) 기능으로 만들어져 있습니다.
그래서 이 저장소를 GitHub Pages나 내 컴퓨터에서 열면 온라인 버튼이 꺼지고, 혼자 하기(컴퓨터 상대)만 할 수 있습니다.
GitHub에서도 온라인을 하려면 `online.js`를 WebSocket 서버 같은 별도 실시간 서버에 연결하도록 바꿔야 합니다.

## 파일 구성

```
index.html      화면 구성 (메뉴, 점수판, 결과 화면, 터치 버튼, 리듬게임 판)
style.css       모든 스타일 (밝은 화면과 어두운 화면 모두 대응)
engine.js       기본 도구, 상수, 입력 상태, 3D 렌더러와 재질
world.js        경기장 무작위 생성, 장애물, 회전 막대, 스프링, 진자, 물
characters.js   캐릭터 10종 모델, 공, 파티클 효과, 효과음
game.js         전투, 잡기와 던지기, 컴퓨터 AI, 물리, 리듬 반격, 캐릭터 능력
rounds.js       탈락과 점수, 캐릭터 애니메이션, 라운드 진행, 결과 화면
online.js       온라인 대전
ui.js           3인칭 카메라, 메인 루프, 메뉴와 캐릭터 미리보기, 터치 조작
```

모든 파일은 한 폴더에 같이 있어야 합니다. 자바스크립트 파일들은 위 순서대로 불러오며, 모듈 없이 일반 스크립트로 서로의 변수와 함수를 공유합니다.
